# シフト給与計算ツール

シフト勤務の給与を自動計算するWebアプリです。

## 機能
- Groqでシフト表の画像から対象者の勤務を読み取り
- 元画像を見ながら日付・出退勤時刻・休憩を修正
- 勤務時間から給与を自動計算
- シンプルで使いやすいUI

## 使用技術
- HTML
- CSS
- JavaScript

## 使い方
`shift_calculator.html` をブラウザで開くだけで使えます。

画像を読み取るには、Groq APIキー、シフト表どおりの対象者名、画像を入力して「画像を解析して計算する」を押します。確認が必要な行は、一覧で入力を直すと集計に反映されます。手入力だけで使う場合はAPIキーが不要です。

日付が1日から月末まで等間隔に並ぶ月間表の写真では、「対象者の行を指定して解析する」を開いてください。年月を選び、対象者の勤務欄を左上、右上、右下、左下の順に囲みます。氏名欄と勤務時間の合計欄は選択の外にします。表の勤務時間を `54:45` のように入力すると、取り込んだシフトの勤務時間と照合できます。
